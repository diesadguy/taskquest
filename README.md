## Запуск проекта

1. Клонировать или открыть проект:

```bash
cd DiplomeTaskManager
````

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать виртуальное окружение:

```bash
.venv\Scripts\activate
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Применить миграции:

```bash
python manage.py migrate
```

6. Создать администратора:

```bash
python manage.py createsuperuser
```

7. Запустить сервер:

```bash
python manage.py runserver
```

8. Открыть сайт:

```text
http://127.0.0.1:8000/
```

## Геймификация

XP начисляется за следующие действия:

| Действие                                | XP |
| --------------------------------------- | -: |
| Создание задачи                         | 10 |
| Выполнение задачи                       | 30 |
| Выполнение до дедлайна                  | 20 |
| Выполнение задачи с высоким приоритетом | 20 |
| Создание комментария                    |  5 |

Формула уровня:

```python
level = int((xp / 100) ** 0.5) + 1
```

Достижения создаются администратором через Django Admin и автоматически выдаются пользователям при выполнении условий.
